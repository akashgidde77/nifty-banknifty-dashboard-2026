# NIFTY 50 & BANK NIFTY – Risk and Return Analysis

## Project Overview
This project analyzes and compares the monthly returns of NIFTY 50 and BANK NIFTY.

## Tools Used
- Python
- SQL
- Microsoft Excel
- Power BI

## Project Files
- Power BI dashboard (.pbix)
- Excel datasets (.xlsx)
- Python analysis code
- SQL queries
- Monthly comparison dataset (.csv)

## Objectives
- Compare monthly returns of both indices.
- Identify positive and negative return months.
- Analyze monthly performance and risk.
- Visualize insights using Power BI.
